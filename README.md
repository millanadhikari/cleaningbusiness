# WeDo Cleaning Services

A single-page Sydney cleaning-company website built with Next.js 16, React 19, Tailwind CSS 4 and shadcn/ui.

## Run locally

Install dependencies with `npm install`, then run `npm run dev`. The preview opens at http://127.0.0.1:5173.

## Build

Run `npm run build`. The static production website is exported to `out/`.

## Scope

Navigation, service, quote and footer buttons are intentionally inactive. The mobile menu and FAQ accordion work locally. No enquiries are submitted. There are no extra content pages.

## Checks

Production build and TypeScript passed. Desktop (1440px) and mobile (390px) layouts were checked for horizontal overflow, image loading, mobile navigation and FAQ interaction. Reduced-motion preferences are supported.

## Expanded design

The page uses locally hosted Manrope and DM Sans fonts, a layered hero, raised service cards, dark feature sections and lime accents. Content includes six service categories, the bond-back guarantee, room-by-room inclusions, optional extras, quote factors, twelve Sydney service areas and ten FAQs. The guarantee wording is draft business copy to align with the actual booking policy before a public launch; no competitor reviews, prices or customer statistics were reused.
